2. Результаты проверки

Проверяем структуру, опасное содержимое, дефекты, видимость и использование clipPath.

Загрузите иконку, чтобы увидеть результаты.

3. Проверка на разных фонах

Изображение отображается с масштабированием и проверяется на белом, тёмном и двух цветных фонах; прозрачность — на шахматном.

4. Очистка и сравнение

Удаляются метаданные, ненужные ID, пустые пути и группы; упрощаются только группы без атрибутов. Точность координат, значения d, points, viewBox и transform не меняются. clipPath удаляется лишь после визуальной проверки.

Сначала загрузите SVG.

SVG Inspector · Автономный HTML + JavaScript для Windows (Edge/Chrome). Проверка пикселей помогает выявить изменения, но не заменяет ручную проверку сложных SVG. Если clipPath влияет на внешний вид, экспорт без него блокируется.
