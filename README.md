# SVG Inspector — локальная проверка и очистка иконок

Автономный инструмент для проверки и очистки SVG-иконок в Windows. Для работы достаточно установленного **Microsoft Edge** или **Google Chrome**. Python, Node.js, подключение к интернету, расширения и локальный сервер не требуются.

## Запуск

1. Скачайте репозиторий: GitHub → **Code → Download ZIP**.
2. Распакуйте ZIP **целиком** в отдельную папку (не запускайте HTML из окна архива).
3. Дважды щёлкните **«Открыть SVG Inspector.cmd»** либо **index.html**.
4. В открывшемся браузере нажмите **«Выбрать SVG-файлы»** или перетащите SVG на страницу.
5. Выберите иконку слева, изучите отчёт и сравните отображение на светлом, тёмном и цветных фонах.
6. Нажмите **«Очистить и проверить»** и сравните иконку до и после.
7. Если пиксельная проверка завершилась успешно, кнопка **«Скачать очищенный SVG»** станет доступна.

> Все операции выполняются в браузере на устройстве пользователя. Файлы никуда не загружаются. После распаковки приложение работает без интернета.

## Что проверяется

- Корректность SVG/XML, допустимость структуры и наличие **viewBox**.
- Наличие геометрических элементов и реальная видимость изображения.
- Касание границ и слишком маленькая видимая область.
- Наличие **clipPath**, обводок, масок, фильтров, текста, сложных стилей.
- Метаданные редакторов (в частности Inkscape), неиспользуемые узлы **defs** и лишние атрибуты **id** (например, `path3825` или `layer1`).
- Ссылки на id из `clipPath`, градиентов, `url(#...)`, CSS, `href` и ARIA сохраняются.
- Потенциально опасные элементы, обработчики событий, внешние ссылки.
- Примерная видимость на белом, тёмном, синем и жёлтом фоне.
- Предпросмотр на прозрачном (шахматном) и произвольном фоне.

Оценка контрастности — эвристическая: она помогает обнаружить слабоконтрастную иконку, но не является автоматической сертификацией WCAG.

## Очистка и защита от повреждений

Перед предварительным просмотром из SVG удаляется исполняемое и потенциально опасное содержимое. При очистке дополнительно удаляются комментарии, служебные метаданные редакторов, ненужные атрибуты и неиспользуемые определения.

SVG с `DOCTYPE` и внутренними XML-сущностями принимаются без запрета. Браузер разбирает сущности (например, цвет или пространство имён из экспорта Adobe), а `DOCTYPE` вместе с объявлениями сущностей и ссылками на внешние DTD удаляется до предпросмотра и экспорта. Внешние DTD не подгружаются; SVG должен содержать необходимые значения сам, иначе остаётся обычная ошибка XML.

Регрессионный пример: `examples/doctype-entities.svg`. Загрузите его и нажмите «Очистить и проверить»: экспорт должен стать доступен, цвет `#123456` и геометрия — сохраниться, а `DOCTYPE`, `ENTITY` и ссылка на `svg11.dtd` — отсутствовать в результате.

**Удаление clipPath зависит от результата визуальной проверки.** Для каждого прямого применения clip-path инструмент пробует его убрать и сравнивает растеризованные изображения. Если удаление меняет рисунок, clipPath сохраняется, а программа сообщает об этом. Удаление действующего clipPath без преобразования геометрии может исказить иконку.

Очистка также удаляет ID, не используемые внутренними ссылками SVG и CSS. ID, необходимые для визуальных эффектов и ссылок, сохраняются. При неоднозначных CSS-селекторах очистка действует консервативно, чтобы сохранить отображение.

### Оптимизация без изменения точности координат

Очиститель дополнительно выполняет следующие безопасные структурные оптимизации:

- Удаляет пустые пути без геометрии (и без внутренних ссылок).
- Удаляет явно невидимые элементы с `display="none"` или `opacity="0"`, если на них и их содержимое никто не ссылается и нет конфликтующих CSS-правил.
- Удаляет пустые группы `<g>`, не имеющие собственных атрибутов.
- Убирает промежуточные `<g>` без атрибутов, сохраняя порядок и атрибуты вложенных элементов.
- Убирает бессодержательные пробелы/переводы строк между геометрическими элементами и пустые атрибуты `class=""`, `style=""`.
- Продолжает удалять неиспользуемые ID, метаданные и лишние определения.

**Не выполняется округление координат, сокращение чисел, изменение команд `path d`, `points`, `viewBox`, `transform`, размеров, обводок и других числовых атрибутов.** Например, `0.123456789012345678` сохраняется без округления до `0.1235`. Значения атрибутов геометрии оставшихся элементов проверяются на точное текстовое совпадение **после сериализации экспортируемого SVG**. Если хотя бы одно из них изменилось, экспорт блокируется.

Если SVG содержит встроенные CSS-стили `<style>`, структурная оптимизация групп, пустых узлов и пробелов пропускается: CSS-селекторы могут зависеть от исходной вложенности. Остальные операции очистки выполняются с последующей проверкой координат и пиксельным сравнением перед экспортом.

Сохранение координат гарантируется для **оставшейся геометрии** и не препятствует удалению неиспользуемых элементов. Полная исходная версия доступна через кнопку «Скачать оригинал».


Перед разрешением экспорта оригинальный безопасный предпросмотр сравнивается с очищенным SVG по пикселям при размерах **96 × 96, 256 × 256 и 512 × 512**. Если есть заметное расхождение, экспорт блокируется.

Сравнение **производится относительно безопасной версии SVG**, из которой до визуализации удалены потенциально опасные элементы. Оно не гарантирует полного совпадения со входным SVG, содержащим скрипты, внешние изображения, динамическую анимацию или ресурсы. Такие файлы требуют дополнительной ручной проверки.

## Ограничения

- Не преобразует clipPath, влияющие на отображение, в обычные пути.
- Не выполняет полноценную топологическую проверку контуров (самопересечения, открытые края, boolean-операции).
- Не переписывает геометрию и не округляет координаты ради уменьшения SVG. Не объединяет или не конвертирует фигуры в пути.
- Не заменяет ручной осмотр сложных SVG с CSS, масками, фильтрами и текстом.
- Не генерирует TTF/WOFF: это отдельная задача, не связанная напрямую с валидацией.
- Максимум **2 МБ на SVG** и **100 SVG за сеанс**.
- Поддерживаются актуальные версии Edge/Chrome.

## Структура проекта

- **index.html** — интерфейс и визуальные состояния.
- **app.js** — анализ SVG, растеризация через Canvas, очистка и экспорт.
- **Открыть SVG Inspector.cmd** — запуск для Windows в браузере по умолчанию.
- **examples/** — примеры для ручной проверки поведения.

Проект без внешних библиотек, CDN и сборки. Для редактирования достаточно изменить HTML или JavaScript и открыть страницу снова.

### Автоматические тесты

При наличии Node.js 18+ можно запустить автоматические тесты структурной оптимизации и сохранения точных координат (используются только встроенные модули Node.js; установка пакетов не требуется):

```bash
node --test tests/optimizer.test.cjs
```

Тесты проверяют сохранение длинных десятичных значений, защиту от округления, поведение групп, CSS и внутренних ссылок. Визуальный контроль после очистки дополнительно выполняет само приложение в браузере.
