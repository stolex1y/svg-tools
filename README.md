# SVG Inspector — локальная проверка и очистка иконок

Автономный SVG-инспектор для Windows. Нужен только установленный **Microsoft Edge** или **Google Chrome**. Python, Node.js, Интернет, расширения и локальный сервер **не нужны**.

## Как запустить (для пользователя)

1. Скачайте репозиторий: GitHub → **Code → Download ZIP**.
2. Распакуйте ZIP **целиком** в отдельную папку (не запускайте HTML из окна архива).
3. Дважды щёлкните **«Открыть SVG Inspector.cmd»** либо **index.html**.
4. В открывшемся браузере нажмите **«Выбрать SVG-файлы»** или перетащите SVG на страницу.
5. Выберите иконку слева, изучите отчёт и сравните отображение на светлом, тёмном и цветных фонах.
6. Нажмите **«Очистить и проверить»** и сравните иконку до и после.
7. Если пиксельная проверка завершилась успешно, кнопка **«Скачать очищенный SVG»** станет доступна.

> Все операции выполняются в браузере на устройстве пользователя. Файлы никуда не загружаются. После распаковки приложение работает без интернета.

## Что проверяется

- Корректность SVG/XML, допустимость структуры и наличие **viewBox**.
- Наличие геометрических элементов и реальная видимость изображения.
- Касание границ и слишком маленькая видимая область.
- Наличие **clipPath**, обводок, масок, фильтров, текста, сложных стилей.
- Метаданные редакторов (в частности Inkscape), неиспользуемые узлы **defs** и лишние атрибуты **id** (например, `path3825` или `layer1`).
- Ссылки на id из `clipPath`, градиентов, `url(#...)`, CSS, `href` и ARIA сохраняются.
- Потенциально опасные элементы, обработчики событий, внешние ссылки.
- Примерная видимость на белом, тёмном, синем и жёлтом фоне.
- Предпросмотр на прозрачном (шахматном) и произвольном фоне.

Оценка контрастности — эвристическая: она помогает обнаружить слабоконтрастную иконку, но не является автоматической сертификацией WCAG.

## Очистка и защита от повреждений

Перед предварительным просмотром из SVG удаляется исполняемое и потенциально опасное содержимое. При очистке дополнительно удаляются комментарии, служебные метаданные редакторов, ненужные атрибуты и неиспользуемые определения.

**clipPath удаляется не безусловно.** Для каждого прямого применения clip-path инструмент пробует его убрать и сравнивает растеризованные изображения. Если удаление меняет рисунок, clipPath остаётся, а программа сообщает об этом. Это намеренное ограничение: удалять действующий клип без преобразования геометрии нельзя без риска искажения иконки.

Очистка также убирает ID, не используемые внутренними ссылками SVG и CSS. ID, нужные для визуальных эффектов и ссылок, сохраняются. При неоднозначных CSS-селекторах очистка действует консервативно, чтобы не сломать отображение.

Перед разрешением экспорта оригинальный безопасный предпросмотр сравнивается с очищенным SVG по пикселям при размерах **96 × 96, 256 × 256 и 512 × 512**. Если есть заметное расхождение, экспорт блокируется.

Важно: сравнение **производится относительно безопасной версии SVG**, из которой до визуализации были удалены потенциально опасные элементы. Оно не доказывает полного совпадения со входным SVG, если во входном файле были скрипты, внешние изображения, динамическая анимация или ресурсы. Уберите подобные конструкции до финального согласования или проверьте файл вручную.

## Ограничения первой версии

- Не преобразует произвольные **реально действующие** clipPath в обычные пути.
- Не выполняет полноценную топологическую проверку контуров (самопересечения, открытые края, boolean-операции).
- Не заменяет ручной осмотр сложных SVG с CSS, масками, фильтрами и текстом.
- Не генерирует TTF/WOFF: это отдельная задача, не связанная напрямую с валидацией.
- Максимум **2 МБ на SVG** и **100 SVG за сеанс**.
- Поддерживаются актуальные версии Edge/Chrome.

## Структура проекта

- **index.html** — интерфейс и визуальные состояния.
- **app.js** — анализ SVG, растеризация через Canvas, очистка и экспорт.
- **Открыть SVG Inspector.cmd** — запуск для Windows в браузере по умолчанию.
- **examples/** — примеры для ручной проверки поведения.

Проект без внешних библиотек, CDNs и сборки. Для редактирования достаточно изменить HTML или JavaScript и открыть страницу снова.
